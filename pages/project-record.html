Inside the CartPole Build

This record connects the browser demo to my maintained original Python/Jupyter CartPole project and its starter-code lineage. It documents the model shape, training constants, action selection, replay update, and the compatibility work needed to keep the notebook readable with newer Gym-style APIs.

Environment and model constants

The maintained notebook preserves the starter DQN configuration. The browser configuration mirrors the same core values so the public simulation uses the same observation/action shape and learning constants.

cartpole.ipynb CONFIGURATION 
ENV_NAME = "CartPole-v1"

GAMMA = 0.95
LEARNING_RATE = 0.001
MEMORY_SIZE = 1_000_000
BATCH_SIZE = 20

EXPLORATION_MAX = 1.0
EXPLORATION_MIN = 0.01
EXPLORATION_DECAY = 0.995
Gamma 0.95

Discount applied to the best predicted value of the next state.

Learning rate 0.001

Optimizer learning rate preserved from the starter notebook.

Replay capacity 1M

Maximum number of experiences retained in replay memory.

Batch size 20

Number of experiences used by each replay pass.

Exploration floor 0.01

Minimum epsilon value after repeated decay.

Exploration decay 0.995

Multiplier applied after replay once a full batch is available.

Network shape

The network accepts the four CartPole observations, passes them through two 24-unit ReLU layers, and returns one linear Q-value for each of the two actions.

DQNSolver KERAS 
self.model = Sequential()
self.model.add(Dense(24, input_shape=(observation_space,), activation="relu"))
self.model.add(Dense(24, activation="relu"))
self.model.add(Dense(self.action_space, activation="linear"))
self.model.compile(
		loss="mse",
		optimizer=Adam(learning_rate=LEARNING_RATE),
)

Epsilon-greedy action selection

The agent explores randomly while the exploration check succeeds. Otherwise it predicts Q-values and selects the action with the highest value.

act() ACTION POLICY 
if np.random.rand() < self.exploration_rate:
		return random.randrange(self.action_space)

q_values = self.model.predict(state, verbose=0)
return np.argmax(q_values[0])

Experience replay

Once replay memory contains at least one full batch, the notebook samples 20 unique experiences, calculates the selected action target, fits the model, and then decays exploration toward its minimum.

experience_replay() DQN UPDATE 
batch = random.sample(self.memory, BATCH_SIZE)

for state, action, reward, state_next, terminal in batch:
		q_update = reward
		if not terminal:
				q_update = reward + GAMMA * np.amax(
						self.model.predict(state_next, verbose=0)[0]
				)

		q_values = self.model.predict(state, verbose=0)
		q_values[0][action] = q_update
		self.model.fit(state, q_values, verbose=0)

self.exploration_rate *= EXPLORATION_DECAY
self.exploration_rate = max(EXPLORATION_MIN, self.exploration_rate)

Notebook compatibility

The maintained notebook accepts both the older Gym return shapes used by the starter implementation and the newer Gymnasium-style reset/step return shapes. This compatibility layer does not change the training constants, reward inversion, replay placement, or model structure.

cartpole.ipynb API ADAPTER 
def reset_environment(env):
		result = env.reset()
		return result[0] if isinstance(result, tuple) else result

def step_environment(env, action):
		result = env.step(action)
		if len(result) == 5:
				state_next, reward, terminated, truncated, info = result
				return state_next, reward, terminated or truncated, info
		return result
