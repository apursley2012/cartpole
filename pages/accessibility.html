Accessibility

This project is designed to target WCAG 2.2 Level AA. It uses semantic landmarks, keyboard-accessible controls, visible focus states, a skip link, reduced-motion support, and accessible names for the simulation canvas and controls.

Automated source checks cannot establish complete WCAG conformance. Manual screen-reader, real-device, zoom, contrast, and keyboard testing should be completed on the deployed production site before making a formal conformance claim.
